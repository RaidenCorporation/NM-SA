# NM-SA (NoModify Source-Available) Licence

A strict, transparent, source-available legal framework designed for independent developers who want complete code transparency without sacrificing control over their project's distribution. 

The NM-SA licence ensures your source code is completely public and auditable for malware verification, while strictly preventing third parties from distributing unauthorised forks, modifications or derivative works.

---

## Quick Summary

| Permission | Allowed | Description |
| :--- | :---: | :--- |
| **Public Auditing & Viewing** | ✅ | Anyone can review the code for safety and integrity. |
| **Private Compilation** | ✅ | Users can compile and run the software for personal use. |
| **Unmodified Sharing** | ✅ | Users can redistribute exact, unchanged copies of the code/software. |
| **Private Modifications** | ✅ | Users can modify the code locally for personal use only. |
| **Distributing Modified Forks** | ❌ | **Strictly Prohibited.** No publishing or hosting derivative works. |

## How to Apply This Licence to Your Repository

To use the NM-SA licence for your own software project, follow these simple steps:

1. Copy the raw text from the [template file](https://github.com/RaidenCorporation/NM-SA-licence/blob/main/LICENCE-TEMPLATE.md?plain=1) in this repository.
2. Create a new file named `LICENCE.md` (or `LICENSE.md`) in the root directory of your project.
3. Paste the text and fill in the bracketed placeholders at the top:
```markdown
Copyright (c) [Year] [Your Name / Company Name]. All rights reserved.
```
```markdown
# `[Utility / Brand Name]` NM SA (NoModify Source-Available) Licence
```

## Why Choose NM-SA?

Traditional open-source licenses (like MIT or GPL) require you to allow anyone to fork, modify and redistribute your work—sometimes even commercially under a different name. 

The NM-SA licence is built for creators who value **malware transparency** and open verification but want to keep their user base unified and prevent fragmentation, copycat distributions or unauthorised third-party variations.
