# Contributing to NM-SA Licence

Thank you for your interest in improving the NM-SA Licence framework! Because this is a legal document framework, contributions work a bit differently than standard software projects.

## How You Can Help
- **Reporting Loopholes:** If you spot an ambiguity or legal edge case in the phrasing that compromises the "NoModify" intent, please open an Issue.
- **Grammar & Clarity:** Typo fixes, phrasing improvements and documentation clarity updates are highly appreciated via Pull Requests.
- **Language:** Typo fixes for South African/British English. eg LICENSE.md instead of LICENCE.md, you should kindly open an Issue.

## Submission Guidelines
1. **Open an Issue First:** For major phrasing adjustments, please open an issue to discuss the change before writing a Pull Request.
2. **Licence Integrity:** Any suggested changes must strictly align with the core philosophy: total code transparency with zero third-party redistribution rights for modified forks.

By contributing to this repository, you agree that your suggested changes will be released under the repository's terms and integrated into the global NM-SA framework.
